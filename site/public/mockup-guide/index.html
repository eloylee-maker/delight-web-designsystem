delight.ai 블로그 본문에 들어가는 목업·다이어그램 패턴 카탈로그입니다. 모든 패턴은 1328px 캔버스에서 렌더되고 본문에는 670px 컬럼에 반응형으로 들어갑니다 — retina 2배 해상도 기준이라 글에 박아도 선명합니다.

Canvas 1328 px · Display column 670 px · Scale ratio 0.5045

사용 규칙 (요약)

  • 본문 1편당 같은 패턴은 최대 2회까지. 같은 카드가 위아래로 반복되면 즉시 다른 패턴으로 교체.
  • 강조 색은 --m-lime (#F2FF66) 한 가지. 여러 색을 동시에 쓰지 않는다.
  • 실 데이터가 없으면 플레이스홀더 명시 — "🖼 IMAGE" 박스, dummy 숫자 그대로 두고 나중에 교체.
  • 제목은 Serrif Medium, 본문·라벨은 Helvetica Now Text. letter-spacing:-0.02em 고정.
  • UI 목업은 항상 macOS traffic light 또는 잘림(crop) 둘 중 하나로 컨텍스트를 준다.
