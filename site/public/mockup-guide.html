Core Rules

Common rules extracted from 20 reference images. Every pattern card is a variation on top of these rules.

Canvas

Output 1328 × Npx with 80px sides and 96px top/bottom padding. Page background #F7F5F0 (warm beige). Let white cards breathe.

Card

White surface #FFFFFF, radius 16–20px, 1px hairline border #E5E1DA. Shadows barely used (very soft if at all).

Type

Body in Helvetica Now Text; large numbers and quotes in Serrif (serif). Labels/pills 12–14px, body 18–22px, card title 22–32px, giant numbers 120–168px.

Accent color

Primary Lime #F2FF66, dark #1A1612. Secondary: green (positive), yellow (warning), red (error), blue/purple (version compare). Low saturation, 1–2 per card.

Pill

Category labels are black pills with white all-caps text. Lime pill used once for emphasis. Radius 6–8px, height 28–32px.

Connectors

Dotted line + small arrow between steps. Vertical 56px, horizontal 64px. Color #9E9890. Avoid thick solid arrows.

Icons

Dark #2B2520 rounded square 56×56, radius 12px, white glyph. Avoid colored icons; use a placeholder if needed.

UI mocks

Show real UI cropped/offset, not full-frame. The crop must imply intent — what is being highlighted. Leave deliberate empty space inside 1328.
